# Vero Shopify Theme — Color Schemes & Section Mapping Guide

This document defines the exact color schemes and design mapping for different sections of the newly designed Vero homepage. The color data has been synced directly from the Figma design and mapped to the 5 modern Dawn scheme slots available in your theme.

---

## 1. Global Color Mappings

We have mapped the custom colors to the 5 modern Dawn scheme slots (Scheme 1 to Scheme 5).

| Scheme Name | Primary Use Case | Hex Code | Visual Reference |
| :--- | :--- | :--- | :--- |
| **Scheme 1** | Main page background, Header, General blocks | `#fffaf3` | Warm Off-White |
| **Scheme 2** | Highlighted blocks (Travelling Essential) | `#f2ebdb` | Beige / Tan |
| **Scheme 3** | Hero Banner background | `#c8e9fc` | Light Sky Blue |
| **Scheme 4** | Announcement Bar, Highlights | `#ffc357` | Yellow / Gold |
| **Scheme 5** | Secondary Banner, Navy Sections | `#00237d` | Navy Blue |

### Global Elements
- **Primary Text Color:** `#363636` (Dark Gray) for light schemes, `#ffffff` for dark schemes.
- **Primary Button Background:** `#00237d` (Navy Blue) for most schemes, `#ffc357` (Gold) for Navy schemes.
- **Primary Button Text:** `#ffffff` (White) for most schemes.

---

## 2. Section-by-Section Configuration Guide

When editing your theme in the Shopify Customizer, please select the specified color scheme for each section to perfectly match the Figma design.

### Section 1: Announcement Bar
- **Color Scheme to Select:** `Scheme 4` (Gold `#ffc357`)
- **Note:** Standard buttons will render as Navy Blue (`#00237d`) with White text.

### Section 2: Header / Navigation
- **Color Scheme to Select:** `Scheme 1` (Warm Off-White `#fffaf3`)
- **Note:** Contains the navigation links, search, and user icons.

### Section 3: Hero Image / Hero Banner ("Cofee Tumbler")
- **Color Scheme to Select:** `Scheme 3` (Light Sky Blue `#c8e9fc`)

### Section 4: Secondary Banner ("FREE SHIPPING all over India")
- **Color Scheme to Select:** `Scheme 5` (Navy Blue `#00237d`)
- **Note:** The text in this section will automatically be White (`#ffffff`), and buttons will automatically render as Gold (`#ffc357`), perfectly matching the Figma logic.

### Section 5: Top Categories & Bestseller
- **Color Scheme to Select:** `Scheme 1` (Warm Off-White `#fffaf3`)

### Section 6: Travelling Essential
- **Color Scheme to Select:** `Scheme 2` (Beige / Tan `#f2ebdb`)
- **Note:** This will give the specific beige background to the entire card layout.

---
*Note: Any new standard sections added to the homepage should default to `Scheme 1` unless they are intended to stand out, in which case `Scheme 2` or `Scheme 5` can be used.*
